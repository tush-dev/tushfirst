# HTML Resume Assignment

This repository contains HTML resume created as part of an assignment.

## Project Overview
The project demonstrates the use of clean and semantic HTML structure to build a simple resume webpage.  
It includes proper usage of headings, paragraphs, lists, tables, and sections.

## Technologies Used
- HTML5

## Features
- Clean and readable HTML structure
- Proper semantic tags
- Well-organized layout for easy understanding

## How to Run
1. Clone the repository
2. Open `index.html` (or `resume.html`) in any web browser

## Live Demo
If GitHub Pages is enabled, the live demo can be accessed from the repository settings.
